## Contingut del document

El document organitza la substitució per pronoms febles per funció sintàctica, en esquemes visuals amb codificació de color:

| Funció | Pronoms |
|---|---|
| Atribut determinat | *el, la, els, les* |
| Atribut indeterminat | *ho* |
| Atribut remarca | *en* |
| CD determinat | *el, la, els, les* |
| CD indeterminat | *en* |
| CD neutre / oració subordinada / pronoms neutres | *ho* |
| CD 1a/2a persona o reflexiu/recíproc | *em, ens, et, us, es/se* |
| CI singular | *li* |
| CI plural | *els* |
| CI 1a/2a persona o reflexiu/recíproc | *em, ens, et, us, es* |
| CRV amb prep. *de* | *en* |
| CRV amb altra preposició | *hi* |
| C.pred. (general) | *hi* |
| C.pred. amb *fer-se, dir-se, nomenar, elegir* | *en* |
| CC general | *hi* |
| CC de lloc amb origen | *en* |
| CN amb prep. *de* | *en* |
| Subjecte (quantitatiu) | *en* |

## Regles especials destacades

1. **Combinació LI + el/la/els/les → L'hi / La hi / Els hi / Les hi**: quan LI (CI) va acompanyat de pronoms d'acusatiu de 3a persona, LI passa a HI i va en segon lloc.
2. **Verbs presentar/oferir**: CI (li, els) davant de CD de 1a/2a persona (em, ens, et, us) → CI passa a HI.
3. **Prohibició LI → HI davant EN**: *Si li cal paper, ja li'n donarem* (no \*li hi).
4. **Prohibició LI → HI davant HO**: *Digues-li-ho de seguida* (no \*hi-ho).
