# Morfologia — Categories gramaticals

> Les **categories gramaticals** són classes de mots amb característiques comunes. Es classifiquen en **variables** (gènere, nombre, persona…) i **invariables**. L'oració s'analitza en tres nivells: morfològic, sintagmàtic i sintàctic.

Veure també: [[Pronoms febles]] · [[Els verbs]] · [[Funcions sintactiques]] · [[Oracions de relatiu]]

---

## Taula de categories

| Categoria | Definició | Variable? | Exemple |
|-----------|-----------|-----------|---------|
| **Determinant** | Delimita el significat del nom | variable (gènere i nombre) | *El meu llapis. Alguns gats.* |
| **Substantiu** | Designa persones, objectes, animals | variable (gènere i nombre) | *La cosina és la mare de la Pepa.* |
| **Adjectiu** | Qualifica el nom | variable (gènere i nombre) | *Flors blanques. Coixins tous.* |
| **Pronom** | Substitueix el nom (o adjectiu, adverbi) | variable (gènere, nombre, persona) | *Ell em crida. Hi va (allà).* |
| **Verb** | Expressa accions, estats, pertinença | variable (nombre, persona, mode, temps) | *Escolta les notícies.* |
| **Adverbi** | Modifica el verb, l'adjectiu o l'adverbi | invariable | *Ara seu. Menja ràpidament.* |
| **Preposició** | Relaciona categories per subordinació | invariable | *Vinc de casa. Surto amb ell.* |
| **Conjunció** | Relaciona categories i oracions | invariable | *En Pep i la Carme. Digues que sí.* |

### Sintagmes
| Sintagma | Nucli | Exemple |
|----------|-------|---------|
| **SN** — nominal | Nom | *Barcelona és una ciutat comtal.* |
| **SV** — verbal | Verb | *En Quim rep els visitants.* |
| **SAdj** — adjectiu | Adjectiu | *Està content de veure't.* |
| **SAdv** — adverbial | Adverbi | *Parla molt bé.* |
| **SPrep** — preposicional | Preposició | *Escric cartes a les amigues.* |

## 1. El substantiu

El substantiu presenta **flexió de gènere i nombre**.

Per a la morfologia verbal, vegeu [[Els verbs]].

### 1.1 El gènere

**Formació bàsica**: femení = masculí + **-a** (*noi/noia, gat/gata*). Poden produir-se canvis:

| Tipus de canvi | Canvi específic | Exemples |
|----------------|-----------------|---------|
| Accentuació | accent desplaçat | *soci/sòcia, capità/capitana, marquès/marquesa* |
| Consonant sorda → sonora | p→b, t→d, c→g, f→v | *llop/lloba, nebot/neboda, amic/amiga, serf/serva* |
| Consonant que duplica | s→ss, l→l·la | *gos/gossa, Marcel/Marcel·la* |
| Vocal | e→a, o→a, eu→a, u→a | *mestre/mestra, europeu/europea, esclau/esclava* |
| Sufixos específics afegits | -na, -ina, -essa | *rei/reina, gall/gallina, jutge/jutgessa, duc/duquessa, baró/baronessa* |
| Sufixos que canvien | -or→-actriu, -òleg→-òloga | *actor/actriu, biòleg/biòloga, arqueòleg/arqueòloga* |
| Femení → masculí | -a → -ot | *bruixa/bruixot, abella/abellot, merla/merlot* |

**Invariables (epicens)**: terminació *-aire* (*el/la cantaire*), *-ista* (*el/la jurista*), *-cida* (*el/la suïcida*). Per als animals, cal especificar *mascle* o *femella* (*el rossinyol mascle, la rossinyol femella*).

**Arrels diferents (heterònims)**: *amo/mestressa, marit/muller, porc/truja, toro/vaca, ase/somera, boc/cabra, dona/home…*

#### Gèneres dobles — significats diferents ⭐

| Substantiu | Masculí | Femení |
|------------|---------|--------|
| **el/la canal** | pas d'aigua | cinta magnetofònica / canonada |
| **la/el còlera** | malaltia infecciosa | la ira |
| **el/la coma** | estat clínic greu | del riu |
| **la/el delta** | del riu | lletra de l'alfabet grec |
| **la/el editorial** | l'empresa | article de fons |
| **el/la fi** | finalitat | acabament |
| **el/la llum** | l'aparell | la claror |
| **l'/la ordre** | arranjament | manament |
| **la/el paleta** | la persona | l'estri |
| **el/la planeta** | l'astre | el destí |
| **el/la pols** | batec | partícules diminutes |
| **el/la pudor** | vergonya | mala olor |
| **el/la son** | estat fisiològic | ganes de dormir |
| **la/el terra** | paviment | planeta |
| **el/la vall** | excavació / fossat | depressió entre muntanyes |

> **Masculins habituals mal classificats**: aforcs, bactori, compte, costum, dot, espanacs, full, lèxic, marge, pebrot, senyal, avantatge, batent, corrent, deute, dubte, front, llegum, pendent, titella.
> **Femenins habituals mal classificats**: alicates, amargor, àncora, apoteosi, au, cercavila, dent, dita, esplendor, frescor, maraió, olor, postres, sida, allau, anàlisi, andana, aroma, calor, clatror, destressa, esperma, estrena, gènesi, onda, orenga, resta, síndrome.

> [!example] Exercicis resolts (noms amb gènere difícil)
> - *ELS afores de la vila.* (afores = masculí plural)
> - *LES anàlisis confirmaran el que em penso.* (anàlisi = femení)
> - *UNA olor de gas.* (olor = femení)
> - *EL compte corrent.* (compte = masculí)
> - *EL corrent d'aire.* (corrent = masculí)
> - *LES postres.* (postres = femení plural)

### 1.2 El nombre

**Formació bàsica**: singular + **-s** (*noi/nois, arbre/arbres, pot/pots, fet/fets, roc/rocs*).

| Acabament del singular | Plural | Exemple |
|------------------------|--------|---------|
| -a àtona | -es | *dona/dones, poma/pomes, roda/rodes, caça/caces* |
| vocal tònica | -ns | *camió/camions, camí/camins, pelegrí/pelegrins, robí/robins* |
| -s, -ç, -x, -ix, -tx | -os | *cas/casos, braç/braços, reflex/reflexos, calaix/calaixos, empat/empats* |
| -sc, -st, -xt, -ig | **-os o -s** | *casc/cascs o cascos, gest/gests o gestos, text/texts o textos, bateg/bategs o batejos* |
| **Invariables** dies setmana | — | *tret de dissabte i diumenge* |
| **Invariables** llatinismes en -us | — | *anus, cactus, cirrus, estratus, eucaliptus, fetus, ficus, virus, tipus…* |
| **Invariables** alguns compostos | — | *trencaclosques, paracaigudes, comptagotes…* |
| **Altres invariables** | — | *fons, temps, pols, urbs, pelvis…* |

**Excepció vocal tònica**: alguns mots afegeixen només *-s* malgrat acabar en vocal tònica: *sofàs, purés, cafès, bebès, bisturís, esquís, hindús, menús, xampús…*

## 2. L'adjectiu

L'adjectiu presenta **flexió de gènere i nombre** (*curt, curta, curts, curtes*).

### 2.1 Formació del gènere i nombre

**De dues terminacions** (ø/-a o -s/-es):

| Canvi | Exemple |
|-------|---------|
| Consonant sorda→sonora: t→d | *buit/buida, esvelt/esvelta* |
| Consonant sorda→sonora: c→g | *groc/groga, rònec/ronega* |
| Canvis ortogràfics: c→qu, g→gu, j→g, i→l·l | *bonic/boniques, amarg/amargues, roig/roges, nul/nul·la* |
| Accent i dièresi | *tebi/tèbia, genuí/genuïna* |
| Sonorització | *cec/cega, borni/bornia* |
| Vocal: e→a, o→a, eu→a, u→a | *ample/àmplia, flonja/flonja, atreu/atreua, esclau/esclava, tou/tova* |
| Increment -n | *fi/fina/fins/fines, bo/bona/bons/bones* |
| Acabats en -s,-ç,-x,-ix,-tx | ø/-a; -os/-es | *fals/falsa/falsos/falses, dolç/dolça/dolços/dolces, convex/convexa/convexos/convexes* |
| Acabats en -sc,-st,-xt,-ig | ø/-a; **-os o -s** / -es | *fresc/fresca/frescos o fresques, trist/trista/tristos o trists/tristes, mixt/mixta/mixts o mixtos* |

**D'una terminació** (invariables en gènere):
- Invariables en sg. i pl.: *-al, -el, -il* (actual/actuals), *-ant, -ent* (elegant/elegants), *-an* (regular/regulars), *-a* (idiota/idiotes, belga/belgues), *-e* (alegre/alegres, simple/simples), *-ble* (amable/amables), *-me* (inèrme/inèrmes), *-ne* (solemne/solemnes), *-aire* (xerraire/xerraires), *-ista* (altruista/altruistes), *-erior* (superior/superiors), *-ar* (regular/regulars)
- Invariables en sg., variables en pl.: *-aç* (audaç/audaços/audaces), *-iç* (feliç/feliços/felices), *-oç* (atroç/atroços/atroces)

> [!warning] Compte!
> Hi ha adjectius que semblen d'una terminació però en fan servir dues: *atent-a, content-a, lent-a, dolent-a, valent-a*.
> Els cultismes en *-lent* fan femení en *-a*: *opulent/opulenta, corpulent/corpulenta*.

### 2.2 Graus de l'adjectiu

| Grau | Formació | Exemple |
|------|----------|---------|
| **Positiu** | forma bàsica | *alt* |
| **Comparatiu d'igualtat** | tan… com | *tan alt com tu* |
| **Comparatiu de superioritat** | més… que | *més alt que tu* |
| **Comparatiu d'inferioritat** | menys… que | *menys alt que tu* |
| **Superlatiu relatiu** | el/la més… de | *el més alt de la classe* |
| **Superlatiu absolut** | molt + adj. / adj. + *-íssim/-a* | *molt alt / altíssim* |

Comparatius irregulars: *bo→millor, dolent→pitjor, gran→major, petit→menor*.

### 2.3 Classificació semàntica

| Tipus | Descripció | Exemple |
|-------|-----------|---------|
| **Qualificatius valoratius** | Qualitat valorada subjectivament | *bonic, intel·ligent, valent* |
| **Qualificatius classificadors** | Classifiquen el nom en una categoria objectiva | *solar* (energia solar), *cardíac* (operació cardíaca) |

> Els **classificadors** no admeten graus ni posició prenominal: *\*molt solar, \*la solar energia*.

## 3. Els determinants

El determinant limita el significat del nom indicant-ne gènere, nombre, proximitat, pertinença, quantitat o indefinició.

### 3.1 L'article definit

| | Singular | Plural |
|--|---------|--------|
| **Davant consonant** | el / la | els / les |
| **Davant vocal (o h)** | l' / la | els / les |

> La forma femenina singular **no** s'apostrofa davant *i, u, hi, hu* àtones: *la idea, la humanitat*.

### 3.2 L'article indefinit

*un / una / uns / unes*

### 3.3 Els demostratius

| | Sing. M | Sing. F | Pl. M | Pl. F | Neutre |
|--|--------|--------|-------|-------|--------|
| **Proximitat** | aquest | aquesta | aquests | aquestes | això / açò |
| **Llunyania** | aquell | aquella | aquells | aquelles | allò |

### 3.4 Els possessius

**Tònics** (precedits d'article davant el nom):

| | Un posseïdor | Sing.M | Sing.F | Pl.M | Pl.F |
|--|-------------|--------|--------|------|------|
| 1a pers. | | meu | meva | meus | meves |
| 2a pers. | | teu | teva | teus | teves |
| 3a pers. | | seu | seva | seus | seves |
| 1a pers. | Més d'un | vostre | nostra | vostres | nostres |
| 2a pers. | Més d'un | nostre | vostra | nostres | vostres |
| 3a pers. | Més d'un | seu / llur | seva | seus / llurs | seves |

**Àtons** (directament davant el nom, sense article):

| | Sing.M | Sing.F | Pl.M | Pl.F |
|--|--------|--------|------|------|
| 1a | mon | ma | mos | mes |
| 2a | ton | ta | tos | tes |
| 3a | son | sa | sos | ses |

> Quan l'expressió s'introdueix amb preposició, cal situar-los al darrere: *a casa meva, a càrrec vostre*.
> Cal evitar possessius redundants quan el context és clar: *Es posa les seves ulleres* → *Es posa les ulleres*.

### 3.5 Els numerals

**Cardinals**: *zero, u/un/una, dos/dues, tres, quatre, cinc, sis, set, vuit, nou, deu, vint, vint-i-u, trenta, quaranta, cinquanta, seixanta, setanta, vuitanta, noranta, cent, dos-cents…*

> Guionet: entre desenes i unitats (30-U: *trenta-u, setanta-tres*); entre unitats i centenes (U-C: *dos-cents, vuit-cents*). El femení de *dos*: *dues noies / dues notes*.

**Ordinals**: *primer/primera, segon/segona, tercer/tercera, quart/quarta…* A partir del cinquè, afegir **-è** (masc.) / **-ena** (fem.): *cinquè/cinquena, desè/desena…*

> Abreviatura: singular → última lletra (1r/1a, 2n/2a, 3r/3a, 4t/4a, 5è/5a…); plural → dues últimes (1rs/1es, 2ns/2es, 3rs/3es, 4ts/4es, 5ns/5es…).

**Partitius**: fraccions. Igual que els ordinals, excepte: *1/2 → mig/mitja/mitjos/mitges*; *1/3 → terç/terça/terços/terces*.

**Múltiples**: *doble, quàdruple, triple, quíntuple, òctuple, cèntuple…*

### 3.6 Els quantitatius

| Variables | Invariables |
|-----------|-------------|
| poc/poca/pocs/poques (de) | que |
| molt/molta/molts/moltes | força |
| tant/tanta/tants/tantes (de) | massa |
| quant/quanta/quants/quantes (de) | més (de) |
| bastant/bastants (de) | menys (de) |
| gaire/gaires (de) | prou (de) |

> - **prou, massa, força** són invariables: *Hi ha prou nois. Tinc massa problemes.*
> - **gaire** = 'molt' en oracions negatives, condicionals i interrogatives: *No hi ha gaire menjar. Has vist gaires alumnes?*
> - Els quantitatius fan funció d'**adverbi** quan modifiquen un verb, adjectiu o adverbi: *Treballa massa. És força ric. Està prou bé.*

**Tant vs tan**:
| TANT | TAN |
|------|-----|
| Davant nom ('en tal quantitat') | Davant adjectiu o adverbi ('en el mateix grau') |
| *Hi havia tantes noies com nois.* | *És tan bonic! Parla tan de pressa.* |

### 3.7 Els indefinits

| Variables | Invariables |
|-----------|-------------|
| tot, tota, tots, totes | cada |
| un, una, uns, unes | cap |
| algun, alguna, alguns, algunes | sengles |
| ambdós, ambdues; tots dos, totes dues | |
| cada un/una; cadascun/cadascuna | |
| mateix, mateixa, mateixos, mateixes | |
| qualsevol, qualssevol, qualsevulla | |
| altre, altra, altres | |
| tal, tals | |

**Interferències castellà → català** ⭐:
| Incorrecte | Correcte |
|-----------|---------|
| *Que tens \*algo per sopar?* | *Que tens alguna cosa/res per sopar?* |
| *Els \*demés tornaran.* | *Els altres/la resta tornaran.* |
| *No he trobat \*ninguna benzinera.* | *No he trobat cap benzinera.* |
| *He comprat \*varios mobles.* | *He trobat alguns/diversos/uns quants mobles.* |
| *\*Qué tal estàs?* | *Com estàs? Com va?* |

> - **mateix** és determinant, no té valor pronominal per substituir el nucli del SN. *Va entrar a la casa i en va mirar tots els racons* (NO: *de la mateixa*).
> - **tot** és invariable davant topònims sense article: *He viatjat per tot Europa.*
> - **res** és pronom ('cap cosa'); no confondre amb l'adverbi de quantitat **gens**.

**Quant vs quan**:
| QUANT | QUAN |
|-------|------|
| Adverbi/adjectiu de quantitat (flexiona en gènere/nombre si és adj.) | Adverbi de temps |
| *Quant val? Quanta gent que hi ha!* | *Quan serà la investidura?* |

### 3.8 La funció pronominal

Les formes de demostratius, possessius, numerals, quantitatius i indefinits poden actuar com a **pronoms** quan substitueixen un nom:
- *Aquest noi va venir ahir.* (Det) → *Aquest va venir ahir.* (Pron)
- *Deixa'm el teu cotxe.* (Det) → *Deixa'm el teu.* (Pron)

## 5. L'adverbi

Els adverbis són **invariables** i modifiquen el verb, l'adjectiu, un altre adverbi o tot el predicat. En alguns casos actuen de **connectors** (*Primerament… seguidament…*).

Una **locució adverbial** és un grup de mots que expressa un contingut indivisible realitzant una funció adverbial (*a trenc d'alba, a tot estirar, a entrada de fosc*).

### 5.1 Adverbis de manera

**Adverbis simples destacats**:

| Adverbi | Significat |
|---------|-----------|
| *així* | d'aquesta manera |
| *alhora / ensems* | al mateix temps, junts |
| *bé / malament* | satisfactòriament / insatisfactòriament |
| *millor / pitjor* | més bé / més malament |
| *debades* | en va, inútilment |
| *corrents* | molt de pressa (≠ *corrent* = gerundi verbal) |
| *dempeus* | dret |
| *sobretot* | per damunt de tot, principalment |
| *exprés* | expressament |

> **bé/ben, mal/malament**: davant adjectiu o adverbi s'usen les formes reduïdes *ben/mal*: *Està bé. / Està ben satisfet. Això està mal expressat.*
> **corrent/corrents**: *S'exercita corrent cada dia* (gerundi verbal) vs. *Fa els deures corrents* (adverbi 'de pressa').

**Adverbis formats amb sufix *-ment***: s'adjunten a la forma **femenina** de l'adjectiu: *covardament, tristament, esportivament, tendrement, violentament, repetidament…* Amb adjectius d'una sola terminació: *alegrement, simplement, lliurement, sàviament…*

> La unió de dos adverbis en *-ment* pot resoldre's escrivint: *Parla amistosament però confusament* (dues formes completes) o *Parla amistosament però confusament* (primera completa, segona abreujada).

**Adverbis amb la mateixa forma que l'adjectiu**: *alt, baix, brut, net, clar, fosc, dret, ferm, just, car, fi* (*Parla alt. Respira fondo. Resisteix ferm. Cal llaurar dret.*)

**Locucions adverbials de manera** (selecció):
- *ràpidament*: de pressa, a corre-cuita, a cuita-corrents, a tot drap, a quatre esparrapades, a tota vela, a tot gas, cames ajudeu-me…
- *lentament*: a poc a poc, xino-xano, xano-xano…
- *bruscament / en poc temps*: tot d'una, tot d'un plegat, en un girar d'ulls, a cop calent (a l'acte)…
- *amb (bona) voluntat*: de tot cor, de bon grat, a cor que vols…
- *sense voluntat*: a contracor, de mal grat, a repèl…
- *amb reflexió*: fil per randa, pam a pam (detalladament), a pams; a tort i a dret (amb raó o sense sense); sense solta ni volta (sense cap motiu raonable); a ulls clucs (superficialment)…
- *amb dificultats*: a penes, amb prou feines (difícilment); a empentes i rodolons (amb entrebancs)…
- *en abundància*: a manta, a dojo, a munts, a carretades…
- *mirar*: de cua d'ull, de fit a fit, de reüll, de front, de gairell…
- *caminar*: de puntetes, a rodolons, a rossegons, de quatre grapes, a peu coix, de les fosques, a les palpentes, de tort, de gairell, de gaió…
- *col·locar el cos*: a collibè, de bocaterossa, de genollons, a la gatzoneta, a peu dret…
- *comprar i pagar*: a compte, al detall, a la menuda, a l'engròs, a la bestreta (pagant per endavant)…

### 5.2 Adverbis de temps

| Referència | Adverbis | Locucions |
|-----------|---------|----------|
| Passat | *abans, antany, ahir, anit* | *abans d'ahir, abans d'ahir l'altre* |
| Present | *ara, suara, enguany, avui* | *a hores d'ara, avui dia* |
| Futur | *després, demà, anit* | *l'endemà, demà passat, demà passat l'altre* |
| Parts del dia | *dejorn (de matí)* | *a la matinada, a punta de dia, a trenc d'alba; de matí, al mati, al migdia, havent dinat; al capvespre, a la tarda, a l'horabaixa, al vespre; a entrada de fosc, cap al tard, a la nit* |
| Freqüència | *sempre, tothora, tosttemps, sovint, adesiara; mai* | *tot sovint, de/les vegades, a voltes, de tant en tant, de tard en tard, ara i adés; una vegada, un cop; mai de la vida, mai més* |
| Temps proper | *tard, aviat, prest, ja* | *d'hora, en breu, de seguida, tantost, tot seguit, al cap de poc, a l'instant, a l'acte* |
| Moment d'un procés | *encara, mentrestant, entretant* | *de primer, d'entrada, d'antuvi, a mitjan, en l'endemig, a la fi, a la darrera, al capdavall, a les acaballes, en acabat, havent acabat* |
| Coincidència/no coincidència | *alhora, ensems* | *a deshora, a destemps* |
| «Aquell moment» | *llavors, aleshores* | *d'aleshores ençà, d'ara endavant, en endavant* |

**Confusions que cal evitar** ⭐:
- *alhora* (adverbi = 'al mateix temps') vs. *a l'hora* (prep. + SN): *A l'hora de fer els deures, sempre fa el roniso.*
- *aleshores* (adverbi = 'llavors') vs. *a les hores* (prep. + SN): *Vull que a les hores dels àpats no us baralleu.*
- *mentrestant* (adverbi, modifica el verb) vs. *mentre* (conjunció relaciona oracions): *Mentre estens la roba, faré el sopar.*
- *quan* (adverbi de temps) vs. *quant* (adverbi de quantitat o determinant).

**Interferències castellà → català** ⭐:
- *\*De quan en quan* → *De tant en tant*
- *\*Al dia següent* → *L'endemà*
- *\*Acte seguit* → *Tot seguit*

**Ús de l'article en determinacions de temps**:
- Generalment sense article amb dies de la setmana: *Dissabte que ve marxarem* (no: *\*El dissabte que ve*).
- Amb article: referència a un dia concret (*el dissabte passat, el jueves pròxim*) o acció reiterativa (*Ens entrenem els dimarts i els dijous*).

### 5.3 Adverbis de lloc

| Referència | Adverbis | Locucions |
|-----------|---------|----------|
| Demostratius | *aquí, ací, ençà; allí, allà, allà, enllà* | *cap aquí, d'aquí estant, cap allà, d'allà estant* |
| De generalització | *pertot, arreu, onsevulla, onsevulga; enlloc* | *a tot arreu, pertot arreu* |
| De situació | *dins, endins, dintre; fora, enfora; davant, endavant; darrere, endarrere; sobre, damunt; dalt, enlaire, daltabaix; sota, dessota; avall, davall; baix, prop, lluny* | *cap endins, a dins; cap enfora; al davant; cap al darrere; al damunt, cap amunt; a dalt, de dalt estant, de dalt a baix, cap a baix; al capdavall; de prop estant; a la vora, a tocar; de lluny, de lluny estant; a la dreta, a l'esquerra, al voltant, a l'entorn, pels volts, als afores* |

**Confusions** ⭐:
- *dalt / baix*: indiquen situació ('a la part alta/baixa'). En locució (*cap a dalt, cap a baix*) indiquen moviment.
- *amunt / avall*: indiquen sempre **direcció**, no situació: *\*La via s'enfila a dalt* → *La via s'enfila amunt.*
- *enlloc*: adverbi = 'a cap banda': *No l'he trobat enlloc.* / *en lloc de*: 'en comptes de' (locució preposicional).
- *pertot*: adverbi = 'a tot arreu' / *per tot*: preposició + determinant: *Dimitiré per tot el que ha passat.*

### 5.4 Adverbis de quantitat

| Referència | Adverbis | Locucions |
|-----------|---------|----------|
| Menys/més quantitat | *poc, gens, gaire; prou; gairebé, quasi, mig; molt; bastant, força; massa; només, sols, solament* | *gens ni mica, no gens, ni mica ni gota; un poc, una mica, un xic; d'allò més; ultra mesura, fora mida* |
| Menys/més grau | *més, menys* | *a més a més, de més a més* |
| Límits i quantitats aproximades | *almenys* | *pel cap alt, a tot estirar, pel cap baix, si fa no fa, més o menys, si més no* |

**Remarques PAU** ⭐:
- **molt / gaire**: *molt* en frases afirmatives; *gaire* = 'molt' en negatives, condicionals i interrogatives: *No m'estima gaire. Si plou gaire, ens quedarem a casa.*
- **bastant / prou**: *bastant* = quantitat regular (ni poc ni molt); *prou* = quantitat suficient. No intercanviables: *Per avui, ja he treballat prou. No és intel·ligent per adonar-se'n.*
- **gaire / massa**: *massa* = 'en excés'. No substituir *gaire* per *\*massa*: *Avui no ha vingut \*massa gent* → *gaire gent.*
- **gens / res**: *gens* = adverbi substituïble per 'poc, molt poc'; *res* = pronom 'cap cosa'. Evitar *res* com a adverbi: *No s'ha esforçat \*res* → *gens.*
- **gairebé**: adverbi de quantitat = 'quasi'. / **gaire bé** (dos mots) = 'gens bé': *No l'he trobat gaire bé.*

**Gens i res en sentit positiu** (interrogatives i condicionals):
- *Que vol res? Que tens gens de gana?* → sentit positiu possible.
- Igualment: *cap, enllloc, mai, ningú* en interrogatives i condicionals.

### 5.5 Adverbis d'afirmació, dubte i negació

| Tipus | Adverbis | Locucions |
|-------|---------|----------|
| **Afirmació** | *sí, oi, també, fins, àdhuc, efectivament, evidentment, indubtablement* | *fins i tot, de debò, de veres, de segur, ben segur, per descomptat, no cal dir-ho* |
| **Dubte** | *potser* | *tal vegada, tal volta, per ventura, si de cas, si per cas* |
| **Negació** | *no, tampoc* | *no pas, no gens, de cap manera, mai de la vida* |

**Remarques PAU** ⭐:
- **\*inclús** → **fins** o **fins i tot**: *\*Inclús en Joan ha arribat* → *Fins en Joan ha arribat d'hora.*
- Incorrecte elidir la conjunció *que*: *\*T'he dit que si hi aniré* → *T'he dit que sí que hi aniré.*
- **potser / pot ser**: *potser* = adverbi de dubte ('tal vegada'); *pot ser* = verb *poder* + *ser*: *Pot ser que tinguis una sorpresa.*
- **\*igual** → **potser**: *\*Igual vénen avui* → *Potser vénen avui.*
- **cap, gens, mai, ningú, enlloc, res** en negació: es recomana reforçar amb *no*: *No, no tinc cap examen de mostra. No hi vaig mai, al teatre.*

### 5.6 Adverbis modalitzadors

Alguns adverbis (especialment els acabats en *-ment*) actuen com a **modalitzadors** de l'enunciat o del locutor:
- *Malauradament, la Joana no es troba bé.* (modalitzador d'actitud del locutor)
- *Primerament, situarem les bases i, seguidament, elaborarem el projecte.* (connectors d'ordre)

## 6. La preposició

La preposició relaciona un element sintàctic amb el seu complement. Són **invariables**. Es classifiquen per:
- **Tonicitat**: febles o fortes
- **Forma**: simples, compostes, locucions prepositives
- **Procedència**: algunes provenen d'adverbis, gerundis o participis

### 6.1 Preposicions febles

| Prep. | Valor | Exemple |
|-------|-------|---------|
| **a** | Lloc, temps; complements de règim verbal | *Anirem a la costa. Renuncio al càrrec.* |
| **en** | Lloc (situació estàtica) | *Viuen en algun indret de la costa. Penso en tu.* |
| **de** | Complement del nom, de l'adjectiu, CRV; sentit partitiu | *L'amic de la Pepa. Era digne del càrrec. Tinc tres amics de l'Argentina.* |
| **amb** | Companyia, instrument, contacte, manera | *Em reuniré amb el meu soci. Parla amb la boca plena.* |
| **per** | Causa, mitjà, agent; CC de mode, lloc, temps | *Actua per altruisme. T'ho envio per correu. El pressupost és concedit per l'Ajuntament.* |
| **per a** | Destinació, finalitat; termes temporals | *Compra regals per a les seves filles. Deixa-ho per al mes que ve.* |

**Canvi i caiguda de preposicions**:
- *en* i *amb* canvien en **a** o **de** davant infinitiu: *S'exercita en el maneig del diccionari* → *S'exercita a manejar el diccionari. L'amenaça amb una expulsió definitiva* → *L'amenaça d'expulsar-lo definitivament.*
- **Caiguda**: totes les preposicions cauen davant la conjunció *que*. Si és massa dur, s'anteposa *el fet*: *Dubta del nomenament* → *Dubta que el nomenin. S'adona del perill* → *S'adona (del fet) que la vida de les espècies perilla.*

**per / per a** ⭐ (distinció PAU):
- Davant **SN**: **per** = motiu/mitjà; **per a** = destinació.
- Davant **infinitiu** (i conjuncions/adverbis), es pot usar sempre **per**: *Farem lloc a la sala per si ve molta gent.* (mitjà) / *Espatllà la cinta per no sentir-la.* (finalitat)

**Complement directe i complement indirecte** ⭐:
- El **CD** d'inanimat s'introdueix **sense preposició**: *Estimo la Maria.*
  - Amb preposició si és pronom personal tònic: *A mi em preocupa molt aquest tema.*
  - Opcionalment davant *tots, tothom*: *Estima (a) tots. Veu (a) tothom.*
  - Per resoldre ambigüitats: *S'estimaven els uns als altres.*
- El **CI** s'introdueix amb **a**: *Dono cèntims als músics del carrer.*

Veure [[Funcions sintactiques]] per a la taula completa de pronominalitzacions.

**Complements de règim verbal** (CRV):
- **a**: renunciar, contribuir, acostumar-se, encomanar-se, aspirar, atrevir-se, procedir…
- **de**: adonar-se, recordar-se, gaudir, burlar-se, riure's, constar, disposar, renegar, dubtar…
- **en**: pensar, creure, consistir, fixar-se…
- **amb**: avenir-se, comptar…

**Expressions de *de / a*** (construccions catalanes ≠ castellà):
- *diferent de* (no: *diferente a*), *por de*, *fer esment de*, *olor de*

**Expressions de lloc**:
- **a** → moviment/direcció: *Vés a la platja. Ens traslladen al barri de Sants.*
- **en** → situació estàtica: *Treballa en una multinacional. Érem en altres terres.*
- Davant article definit sempre *a*: *S'estan al sofà. Es quedaran a la muntanya.*
- Davant demostratius i indefinits: recomanat *en*, possible *a*: *Viu en/a un pis de l'Eixample.*
- Davant topònims, obligatori *a*: *Ens vam quedar a Tarragona. Viu a Salses.*

**Expressions de temps**:
- **Parts del dia** → *a*: *M'agrada contemplar-te al matí. Al capvespre faig una dormideta.*
- **Mesos** → *a* o *per*: *Pel maig, cada dia un raig. Al desembre tothom a jeure.*
- **Estacions** → *a la primavera/tardor*; *a l'estiu/hivern* o *per*: *A la primavera, el bosc s'omple de colors.*
- **Infinitiu temporal** (llengua formal) → *en*: *En arribar a casa, faré el sopar.*

**Mitjà de locomoció**: tant *amb* com *en*: *Vaig amb/en avió.*

### 6.2 Preposicions fortes simples

| Prep. | Valor |
|-------|-------|
| *entre* | situació entre límits; comparació, distribució, distinció |
| *segons* | acord o conformitat |
| *malgrat* | obstacle sense efecte |
| *sense* | absència, falta, exclusió, privació |
| *ultra* | suma, addició ('a més, a més a més') |
| *contra* | oposició, recolzament, contacte |
| *vers / devers / envers* | cap al costat de; cap a; cap a la banda de / en relació amb |

### 6.3 Preposicions fortes compostes

| Prep. | Valor |
|-------|-------|
| *cap a* | direcció, aproximació cap a un lloc o moment |
| *des de* | origen a partir del qual s'inicia un moviment |
| *fins a* | límit final d'un moviment, espai de temps |

**Preposicions provinents d'altres categories**:
- **Adverbis**: *abans de, després de, dalt (de), davall (de), davant (de), darrere (de), dins (de), fora de, sobre (de), sota (de), prop de, lluny de, vora (de)*
- **Gerundis i participis**: *durant, mitjançant, llevat (de), tret (de), excepte, passant*
- **Adjectius**: *a mitjan* (cap a la meitat)

### 6.4 Locucions prepositives

| Locució | Valor |
|---------|-------|
| *a desgrat de / a despit de / a pesar de* | malgrat algun impediment |
| *a fi de / per tal de / de cara a / a fi i efecte de* | per aconseguir |
| *a causa de / per raó de / gràcies a / per culpa de* | motivat per |
| *a excepció de / tret de / fora de* | excloent |
| *a força de / a còpia de* | amb insistència o abundor |
| *de por de / per por de* | temença |
| *en lloc de / en comptes de* | substituint una cosa per una altra |
| *ran de / arran de / tocant a / al costat de* | gairebé tocant, gairebé al mateix nivell |
| *quant a / pel que fa a / amb relació a* | en el que es refereix a |

**Remarques PAU** ⭐:
- ***fins / fins a / cap / cap a***: les formes compostes s'usen davant l'article. Davant adverbis es redueixen: *cap aquí, fins allà, fins ara.* Davant *que*: *No tornarem fins que m'ho demanin.*
- ***degut a***: incorrecte com a locució de causa → substituir per *a causa de*. Correcte referit al participi del verb *deure*: *Els conflictes són deguts a malentesos.*
- ***com a / com***: *com a* = 'en qualitat de'; *com* = 'igual que, com si fos': *Li parlo com a soci. Va restar com hipnotitzat.*
- ***\*en quant a*** → ***quant a***: *Quant a tu, ja en parlarem.*
- ***\*a mitjans de*** → ***a mitjan***: *Tornarà a mitjan novembre.*
- ***\*junt a*** → ***tocant a / al costat de***: *El salze es troba tocant al cementiri.*
- ***amb relació a*** = 'pel que fa a' / ***en relació amb*** = 'en correspondència amb, en connexió amb'.

## 7. La conjunció

La conjunció relaciona categories i oracions per coordinació o subordinació. És **invariable**.

| Tipus | Conjuncions |
|-------|-------------|
| **Coordinants copulatives** | *i* (forma *e* davant *i-*), *ni* |
| **Coordinants disjuntives** | *o* (forma *u* davant *o-*) |
| **Coordinants adversatives** | *però, sinó, ara… ara, bé… bé, ja… ja* |
| **Subordinants completives** | *que, si* |
| **Subordinants causals** | *perquè, car, ja que, atès que, puix que* |
| **Subordinants finals** | *perquè + subj., a fi que, per tal que* |
| **Subordinants concessives** | *encara que, tot i que, malgrat que, bé que, si bé* |
| **Subordinants temporals** | *quan, mentre, abans que, després que, tan aviat com, en acabar* |
| **Subordinants condicionals** | *si, sempre que, a condició que, en cas que* |
| **Subordinants comparatives** | *com, tant com, més que, menys que* |
| **Subordinants consecutives** | *tan/tant… que, de manera que* |

> Per a usos de les conjuncions subordinants en oracions compostes, veure [[Funcions sintactiques]].

## 9. Formació de mots

### 9.1 Derivació

Creació de mots nous afegint **afixos** (prefixos o sufixos) a un lexema:

| Mecanisme | Exemple |
|-----------|---------|
| **Prefix** | *des-* + *fer* → *desfer*; *re-* + *escriure* → *reescriure* |
| **Sufix** | *camp* + *-estre* → *campestre*; *llet* + *-er* → *lleter* |
| **Sufix zero** (derivació regressiva) | *cantar* → *cant* (supressió de la terminació verbal) |

Sufixos comuns: *-ment* (adverbi), *-ció/-sió* (substantiu de procés), *-dor/-dora* (agent), *-ble* (possibilitat), *-isme/-ista* (tendència/seguidor)…

### 9.2 Composició

Creació de mots nous per unió de dos o més lexemes:

| Tipus | Exemple |
|-------|---------|
| Nom + nom | *rentaplats, paravents* |
| Nom + adj | *maldecap, benvingut* |
| Verb + nom | *guardabosc, llevaneu* |
| Adj + adj | *sordmut, agredolç* |
| Compostos cultes (grec/llatí) | *hidro- + avió = hidroavió, antropo- + logia = antropologia* |

### 9.3 Parasíntesi

Combinació simultània de composició i derivació, o de prefix + lexema + sufix (sense que existeixin les formes intermèdies):
- *en-* + *terra* + *-ar* → *enterrar* (no existeix *\*enterr* ni *\*entar*)
- *a-* + *poc a poc* + *-ar* → *apacar*

### 9.4 Abreviacions

| Mecanisme | Descripció | Exemple |
|-----------|-----------|---------|
| **Abreviatura** | Reducció gràfica; es llegeix la paraula sencera | *Dr.* (doctor), *pàg.* (pàgina), *núm.* (número) |
| **Sigla** | Inicials de les paraules d'un grup | *ONU, UNESCO, RENFE* |
| **Acrònim** | Sigla que es llegeix com una paraula; pot admetre plural | *l'OTAN, els ovnis* |
| **Truncament** | Reducció popular: apòcope (tall al final) o aferesi (tall al principi) | *bici* (bicicleta), *profe* (professor), *bus* (autobús) |

### 9.5 Neologismes

Mots nous creats per necessitat expressiva o tecnològica:
- **Manlleus** (d'altres llengües): *estrès* (angl. *stress*), *xampú* (fr. *shampooing*)
- **Calcs** (traducció literal): *rentadora* (de cast. *lavadora*)
- **Derivació/composició interna**: *informàtica, maquinari, programari*
- **Formació culta** (grec/llatí): *telemàtica, biotecnologia*

| Forma incorrecta | Forma correcta |

| *\*inclús* | *fins / fins i tot* |

| *\*De quan en quan* | *De tant en tant* |
| *\*Al dia següent* | *L'endemà* |
| *\*Acte seguit* | *Tot seguit* |
| *\*ninguna/ningún* | *cap* |
| *\*algo* | *alguna cosa / res* |
| *\*demés* | *els altres / la resta* |
| *\*varios* | *diversos / uns quants / alguns* |
| *\*Qué tal estàs?* | *Com estàs? Com va?* |
| *\*degut a* (causa) | *a causa de / per culpa de* |
