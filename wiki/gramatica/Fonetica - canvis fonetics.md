# Fonètica — Canvis fonètics

Els canvis fonètics es produeixen perquè les consonants s'adapten al context fònic dels sons veïns (assimilació, dissimilació) o perquè el sistema simplifica grups consonàntics. S'organitzen en quatre grans fenòmens.

---

## 1. Canvi en el mode d'articulació

Les **consonants oclusives sonores** [b], [d], [g] perden el mode d'articulació oclusiu i es realitzen com a **aproximants** (no barren el pas de l'aire, sinó que aproximen els òrgans articulatoris) en els contextos següents:

### Es realitzen oclusives [b], [d], [g]
| Context | Exemples |
|---|---|
| Principi absolut de mot / darrere de pausa | *boda* [b], *dita* [d], *gossa* [g] |
| Darrere de nasal | *imbècil* [b], *indí* [d], *ungüent* [g] |
| Darrere d'oclusiva | *capverd* [b], *cabdal* [d] |

### Es realitzen aproximants [β], [ð], [ɣ]
| Context | Exemples |
|---|---|
| Entre vocals | *rebia* [β], *quedar* [ð], *regar* [ɣ]; *la boda* [β], *una dita* [ð], *la gossa* [ɣ] |
| Darrere de fricativa | *baf bullent* [β], *desdir* [ð], *esgarip* [ɣ] |
| Darrere d'africada | *pots barallar-t'hi* [β], *vaig de bòlit* [ð], *faig gana* [ɣ] |

> [!note] Remarques
> - La [d] es realitza **oclusiva** darrere de lateral: *maldestre*, *el dit*
> - La [b] i la [g] es realitzen **aproximants** darrere de lateral: *albara*, *algú*

## 2. Canvi en el punt d'articulació

### Assimilació de la nasal [n]
El so nasal **[n]** assimila el punt d'articulació del so que el segueix, tant a l'interior de mot com entre mots consecutius. Quan [n] és alveolar, esdevé:

| Davant de | S'articula | Exemples |
|---|---|---|
| Bilabials [p], [b], [m] | [m] | *canvi* [kámbi]; *un pot* [umpɔt] |
| Dentals [t], [d] | [n̪] | *cantant* [kəntán]; *un dia* [undíə] |
| Palatals [ʎ], [ʃ], [ɲ] | [ɲ] | *un lluc* [uɲʎús]; *un jove* [uɲʒóβə]; *un xai* [uɲʃáj]; *ingenu* [iɲʒénu] |
| Velars [k], [g] | [ŋ] | *cranc* [kráŋk]; *un got* [uŋgɔt] |
| Labiodentals [f], [v] | [ɱ] | *càntora* [kámfərə]; *infermera* [iɱfərmérə] |

### Assimilació del lateral [l]
El lateral **[l]**, sempre que va seguit d'una consonant, assimila el punt d'articulació de la consonant que el segueix:

- **Dentalització:** Es realitza [l̪] davant de consonant dental [t], [d] — *altar* [əl̪tál], *el dia* [əl̪déə], *caldea* [kəl̪déə]
- **Palatalització:** Es realitza [ʎ] davant de consonant palatal [ʃ], [ʒ], [ɲ] — *el llavi* [əʎʎáβi], *el gebre* [əʎʒéβrə], *el nyap* [əʎɲáp], *el xicot* [əʎʃikɔt]
- **Velarització:** Es realitza [ɫ] sempre a excepció d'inici absolut — *la Lola* [ɫəɫóɫə]

## 3. Ensordiment i sonorització

### A fi de mot
- Les **consonants oclusives sonores** [b], [d], [g] perden la sonoritat en posició final absoluta (darrere de pausa) i esdevenen sordes [p], [t], [k] respectivament.
- Les **fricatives i africades** en posició final també perden la sonoritat; quan hi ha hagut ensordiment, cal fixar-se en el so dels derivats.

| Sonora → Sorda | Exemples |
|---|---|
| [b] → [p] | *tub* [p], *calb* [p] |
| [d] → [t] | *fred* [t] |
| [g] → [k] | *sud* [t], *mag* [k], *anàleg* [k] |
| [z] → [s] | *grisor, grisenc > gris* [s]; *casos, casuística > cas* [z→s] |
| [dz] → [ts] | *mitja, mitjana > mig; lletja, lletjor > lleig* |

### Entre mots consecutius (so consonàntic + so consonàntic)
Les consonants oclusives, fricatives i africades esdevenen sordes o sonores segons la característica del so que les segueix. **Governa el canvi el so de darrere.**

- **Ensordiment:** una consonant sonora seguida de consonant sorda esdevé sorda.

| Exemple | Resultat |
|---|---|
| *club privat* | [p] |
| *fred polar* | [t] |
| *mag popular* | [k] |

- **Sonorització:** una consonant sorda seguida de consonant sonora esdevé sonora.

| Exemple | Resultat |
|---|---|
| *pop bellugadís* | [b] |
| *foc nou* | [g] |
| *dies de sol* | [z] |
| *vaig de corcoll* | [dz] |

### Entre mots consecutius (so consonàntic + so vocàlic)
En el context següent les consonants oclusives es comporten diferent de les fricatives i africades:

- **Oclusives:** les vocals **enсordeixen** les oclusives sonores.
  - *tub estret* [p], *fred humit* [t], *mag ambiciós* [k]
- **Fricatives i africades:** les vocals **sonoritzen** les fricatives i africades sordes.
  - *baf agre* [v], *els amics* [z], *cruix el dit* [ʒ], *vaig amb tu* [dz]

### A l'interior de mot (sonorització per assimilació)
A l'interior de mot es produeix **sonorització**. La característica del so que segueix (inici de sil·laba) influeix en el so de davant — sempre trobem dues consonants sordes o sonores en contacte:

| Sorda → Sonora | Exemples |
|---|---|
| [pt] → [bd] | *subterfugi* [pt→bd] |
| [pk] → [bk] | *subdelegat* [bd], *subclasse* [pk] |
| [ps] → [bs] | *subsidi* [ps] |
| [bs] → [bz] | *subjecte* [bz] |
| [zm] → [zm] | *esmolar* [zm] |
| [xp] → [zp] | *espant* [xp→zp] |
| [st] → [zd] | *estrany* [st] |
| [zy] → [zy] | *esgüell* [zy] |
| [zβ] | *esbombar* [zβ] |

## 4. Emmudiment, sensibilització i geminació

### Emmudiment
L'**emmudiment** és el fenomen pel qual un so deixa de realitzar-se fonèticament en un context determinat:

- Les oclusives **p** i **b** precedides de **m**: *camp, rumb, llamp, compte…*
- Les oclusives **d** i **t** precedides de **n** i **l**: *dent, alt, sant, profund…*
- Les vibrants en posició final (infinitius, sufixos de derivació): *anar, pastisser, decorador…*
- La **r** de la paraula *arbre* i del verb *prendre* i compostos: *aprendre, reprendre, sorprendre…*
- Per contacte amb sons idèntics o amb sons amb el punt d'articulació molt pròxim: *els somnis, les rodes, els xinesos…*

### Sensibilització
La **sensibilització** fa referència al fenomen pel qual sons que normalment no es pronuncien, en determinats contextos tornen a aparèixer:

- Infinitius i gerundis seguits de pronom feble: *anar-hi, tornant-hi, fent-ho…*
- *sant* + vocal: *sant Antoni, sant Elm…*
- *amb* + vocal: *amb ell, amb això…*
- *vint* + vocal: *vint-i-dos, vint homes…*

### Geminació
La **geminació** és la pronúncia doblada de consonants. Es produeix quan:

1. **Etimològica:** conservació del grup consonàntic original — *connexió, col·laborar, immensitat, addicte…*
   - Afecta els grups **-bl-** i **-gl-** precedits de vocal tònica:
     - *doble* → [dòbblə], *segle* → [sègglə]

2. **Per assimilació total** d'un so a les característiques del so que el segueix. Afecta la **t**, la **d** i la **b** en els contextos següents:

| Paraula | Transcripció |
|---|---|
| *atlàntic* | [əlˈlántik] |
| *ametlla* | [əméʎʎə] |
| *ètnic* | [énnɪk] |
| *futbol* | [fubbɔl] |
| *submarí* | [summərí] |
| *advertir* | [əbbərtíf] |

## Resum esquemàtic

| Fenomen | Mecanisme | Paraula clau |
|---|---|---|
| Canvi de mode | Oclusiva → aproximant en posició intervocàlica | [b]→[β], [d]→[ð], [g]→[ɣ] |
| Canvi de punt | [n] i [l] s'assimilen al punt del so veí | Assimilació |
| Ensordiment | Sonora → sorda a final de mot o davant de sorda | [b]→[p], [d]→[t], [g]→[k] |
| Sonorització | Sorda → sonora davant de sonora | [p]→[b], [t]→[d], [k]→[g] |
| Emmudiment | So deixa de pronunciar-se | -r final, -p/-b davant de m |
| Sensibilització | So emmudiment torna a aparèixer | *sant Antoni*, *anar-hi* |
| Geminació | Consonant es pronuncia doble | *col·laborar*, *futbol* |
