# Overview — Català PAU

## Objectiu
Preparar la prova de **Llengua catalana i literatura** de les PAU (Selectivitat de Catalunya).

## Estructura de la prova
La prova consta típicament de:
1. **Comprensió lectora i expressió escrita** — text + preguntes + redacció
2. **Reflexió lingüística** — gramàtica, lèxic, ortografia
3. **Literatura** — comentari sobre les lectures obligatòries

## Eixos d'estudi
- [[gramatica/_index|Gramàtica]] — ortografia, morfologia, sintaxi
- [[literatura/_index|Literatura]] — moviments, gèneres, contextos
- [[autors/_index|Autors]] — biografia, obra, context
- [[obres/_index|Obres]] — anàlisi de cada lectura obligatòria
- [[tecniques/_index|Tècniques]] — comentari de text, redacció
